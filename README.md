# 🛒 Excel Dashboard: Online Store Annual Report

A dynamic and interactive dashboard built using **Microsoft Excel**, designed to analyze the annual performance of an online retail business. This project demonstrates how Excel can be used for advanced data visualization, customer segmentation, and sales analysis—ideal for students and aspiring data professionals.


## 📘 Introduction

This Excel dashboard provides a comprehensive overview of an online store’s performance across geography, age group, gender, and sales channels. It uses slicers, charts, and formulas to transform raw data into actionable insights—without relying on external BI tools.


## 🧭 Dashboard Overview

The dashboard is structured to offer:

- A clean, user-friendly layout
- Interactive filters for customized views
- Visual summaries of key performance indicators
- Segmentation by demographics and sales platforms

## 🧩 Interactive Filters

The dashboard includes slicers for:

- **Channel**
- **Month**
- **Store**
- **Age Group**

These filters allow users to explore specific segments and customize the data view.
